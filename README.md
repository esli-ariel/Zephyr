# 🌪️ Zéphyr

Zéphyr est un assistant intelligent multimodal destiné à
l'apprentissage des langues.

## 🎯 Vision

Zéphyr doit progressivement devenir un assistant capable de :

- 🧠 comprendre le langage naturel ;
- 💬 tenir des conversations ;
- 🎤 écouter l'utilisateur ;
- 🔊 parler ;
- 📷 voir à travers la caméra ;
- ✋ reconnaître certains gestes ;
- 📚 enseigner une langue ;
- 📝 générer des exercices ;
- 📊 suivre les progrès ;
- 🧠 mémoriser les difficultés ;
- 🤖 prendre des initiatives pédagogiques ;
- 👤 posséder un avatar ;
- 🧍 posséder éventuellement un corps animé.
